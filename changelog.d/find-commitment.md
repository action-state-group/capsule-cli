- `capsulectl commitment find` finds an advertised evidence commitment from a directory record or ARD file (`--directory`), an A2A Agent Card (`--a2a-card`) or a Nostr relay (`--nostr-relay` with `--node-id`), or reads octets you hold (`--file`), and prints a verdict with named reasons from the carriers binding's verifier rules: the commitment's signature, the key match (`--node-key`, the asker's own; without it the verdict is `KEY_NOT_BOUND`, exit 3), the staple digests, the newest `issued_at`, and a consistency check against the node (it asks a node that names an https endpoint with the http binding for a fresh `history_card/1`; `--offline` asks nothing). The verdict labels the node `witnessed since <time>` or `unwitnessed`, derived from the receipts you give (`--receipt`, `--anchor-witness-policy`), never from what the node or carrier says. For an unwitnessed node it keeps the first checkpoint it saw per node key and stream (`--pin-dir`, `--no-pin`) and fails any later answer that cannot prove consistency to it. The verb reaches only public hosts (`--allow-private-network` lifts that) and follows no redirect. `--refuse-unwitnessed` refuses a node no witness in your policy vouches for.
