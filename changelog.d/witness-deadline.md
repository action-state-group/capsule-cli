- **Added:** `cli.DeliverWitnessBy` takes a deadline for one witness delivery call, so a library caller with a time budget (evidencebook's `deal tick`) no longer waits up to the client's 30 s on a witness that accepts and then hangs. A request still running at the deadline is recorded like any timed-out delivery (`witness_timeout` once it reached the witness), and the deadline is shared by every row the call sends. A row that would start with less than 2 s left is not sent and stays as it was. `cli.DeliverWitness` is unchanged (#645).
