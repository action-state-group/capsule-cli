- `profile update --wording` accepts a wording pack that lacks keys this release uses (a plugin built before a key was added) instead of refusing it, so an older plugin keeps installing on a newer core. The pin behaves as at run time: the whole built-in pack speaks, never a mix. The output carries a `wording_notice` naming the missing keys, and `doctor --install-check` adds a `warnings` list with the same line (`ok` and the exit code are unchanged).
