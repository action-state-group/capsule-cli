- **Breaking:** the deal-format verify code leaves the core (capsule-cli#428 step 5). `capsulectl verify --bundle` no longer reads an `x-deal-v0` or `x-deal-v1` report, a sale or history extension, or the `x-cadence-witness/v0` chain: each is listed `uninterpreted`, the verdict is the generic checks', and the printed line, on any verdict and for composed members too, names them ("Not checked here: KIND, which this tool does not interpret; check these with the tool that defines them"). A witness chain carried only in such an extension adds no witness claim; the neutral replacement is `parent-log-witness/v1` (capsule-cli#608). Page writing and `presentation list` follow the same generic verdict. Removed Go API: `CheckDealStandaloneReport`, `DealReportEntry`, `SetDealV1ReportVerifier`, the `Deal*` report, cadence, sale and history names, `CadenceChainOf`, `Profile.DealCadence` and `DealDefaultWitness*`; capsulectl-deal must carry its own copies first (evidencebook#735), then pin this release. `verify --capsule` no longer has a special message for a deal export. `commitment publish --community` takes any lowercase token (it accepted only three names), and the help and README name no company plugin or community.
