- **Breaking:** the deal-format verify code leaves the core (capsule-cli#428 step 5). `capsulectl verify --bundle` no longer reads an `x-deal-v0` or `x-deal-v1` report, a sale or history extension, or the `x-cadence-witness/v0` chain: each is listed `uninterpreted`, the verdict is the generic checks', and the printed line names them ("Not checked here: KIND, which this tool does not interpret"). A witness chain carried only in such an extension adds no witness claim; the neutral replacement is `parent-log-witness/v1` (capsule-cli#608). Removed Go API: `CheckDealStandaloneReport`, `DealReportEntry`, `SetDealV1ReportVerifier`, the `Deal*` report, cadence, sale and history names, `CadenceChainOf`, `Profile.DealCadence` and `DealDefaultWitness*`; a plugin carries its own copies. `verify --capsule` no longer has a special message for a deal export. `commitment publish --community` takes any lowercase token (it accepted only three names), and the help and README name no plugin or community.
